# 方大同纪念空间

一个以方大同音乐与作品为主题的单页纪念网站，用专辑、时间线与影像画廊串联其音乐历程。

## 页面内容

- **首页主视觉**：呈现艺名、中文名、年份和专辑信息，以双层人像、聚光遮罩与签名构成开场画面。
- **简介与作品**：介绍页面中的人物简介，并以专辑封面网格展示作品目录。
- **精选与时间线**：通过精选专辑轮播和可展开的年份条目浏览页面所列内容。
- **影像与厂牌**：包含图片画廊、厂牌标识与纪念引言。

## 界面与交互

页面采用黑色底色与金色点缀，并以衬线字体、纹理背景和大幅图片营造纪念氛围。导航菜单可展开；首页聚光区域会随桌面指针移动，滚动时主视觉以动画过渡；页面还包含滚动显现、数字计数、精选轮播、时间线展开和顺滑滚动开关。布局针对窄屏调整了统计卡片、简介、轮播和画廊的排列。

## 技术

- 原生 HTML、CSS 与 JavaScript（页面脚本使用 ES module）
- GSAP 3.12.5 与 ScrollTrigger，用于滚动相关动画
- Google Fonts 上的 Playfair Display 字体
- 图片、背景、签名 SVG 等静态素材存放于 `assets/`

## 本地预览

仓库根目录包含 `index.html`，没有提供 `package.json` 或项目依赖安装脚本。可用 Python 启动简单静态文件服务器：

```bash
cd fong-fong
python3 -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。页面引用的 GSAP 与字体从外部 CDN 加载，预览时需要网络连接。

## 素材与发布提示

仓库包含人物照片、专辑封面、厂牌标识及其他图片。公开发布或用于宣传视频前，请核实这些素材、音乐/歌词文字、肖像与商标的授权范围；仓库中未见素材来源或授权说明。页面中的社交链接目前使用 `#` 占位，顶部 Listen 按钮打开 Spotify 首页。
